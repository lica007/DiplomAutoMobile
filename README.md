# Приложение «Мобильный хоспис»

## Описание приложения
Приложение даёт функционал по работе с новостями хосписа и включает в себя:
- Информацию о новостях и функционал для работы с ними
- Тематические цитаты
- Информацию о приложении

## Процедура запуска автотестов
1. Клонировать репозиторий командой: *git clone*
2. Открыть проект в **Android Studio**
3. Запустить эмулятор Эмулятор Pixel 4 API 29 Android 10.0("Q") x86 
4. Запустить тесты командой: *./gradlew connectedAndroidTest*

## Процедура запуска отчета
1. После завершения автотестов необходимо на эмуляторе (Device Explorer), перейти в директорию /data/data/ru.iteco.fmhandroid.ui/files/allure-results , и с помощью Save As сохранить отчеты в папку allure-result в корневой директории проекта
2. Для запуска отчета в терминале ввести команду: *allure serve*
