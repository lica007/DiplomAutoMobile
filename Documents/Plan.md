### 1. Общая информация

   Тестируется мобильное Android‑приложение, предназначенное для работы с новостями хосписа.
   Приложение включает следующий функционал:
   - Авторизация пользователя 
   - Просмотр тематических цитат 
   - Просмотр новостей 
   - Фильтрация и сортировка новостей 
   - Панель управления новостями (создание, редактирование, удаление)
   - Просмотр информации о приложении 
   - Выход из учетной записи

Тестирование проводится на Android API 29 (в соответствии с требованиями).

### 2. Типы тестирования

   В рамках проекта выполняются:
   - Функциональное тестирование 
   - UI‑тестирование 
   - Проверка граничных значений 
   - Тестирование негативных сценариев 
   - Тестирование устойчивости (поворот экрана)
   - Проверка навигации

### 3. Тестовая среда

- Android Studio Panda 3 | 2025.3.3 Patch 1
- Эмулятор Android API 29
- Android 10.0
- Операционная система Windows
- Язык приложения — русский

### 4. Подход к тестированию
#### 4.1 Ручное тестирование
На первом этапе составляется чек‑лист, покрывающий весь основной функционал приложения.
Затем на основе чек‑листа формируются детализированные тест‑кейсы.
#### 4.2 Автоматизация тестирования

Автоматизация планируется для следующих сценариев:
- Авторизация 
- Создание новости 
- Редактирование новости 
- Фильтрация 
- Проверка отображения новостей

Для автоматизации используются:
- Espresso 
- Android JUnit4 
- Allure (для формирования отчетов)

Автотесты покрывают основные позитивные сценарии и критичную логику приложения.

### 5.Критерии начала тестирования

Тестирование начинается при выполнении следующих условий:
- Приложение успешно устанавливается 
- Приложение запускается без критических ошибок 
- Основные экраны доступны

### 6.Критерии завершения тестирования

Тестирование считается завершённым, если:
- Проверен весь функционал согласно чек‑листу
- Подготовлены тест‑кейсы 
- Подготовлен отчёт о тестировании

### 7. Риски

Возможные риски:
- Отсутствие подробных требований 
- Неописанная логика валидации 
- Различия поведения при повороте экрана
